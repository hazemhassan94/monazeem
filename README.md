# مُنظم — منظم حياة مدرس
تصميم حازم حسن

تطبيق Flutter يشتغل كـ PWA على الآيفون والأندرويد، وله إعداد تطبيق iOS أصلي لفتح أرقام الدخل ببصمة الوجه. البيانات كلها محفوظة داخل الجهاز (shared_preferences → localStorage في الـ PWA).

## التشغيل (مرة واحدة)

```bash
# 1) اعمل مشروع Flutter فاضي
flutter create --platforms=web,ios --project-name monazzem monazzem_app
cd monazzem_app

# 2) انسخ ملفات المشروع فوقه (اعمل Replace)، بما فيها pubspec.yaml و lib/ و ios/
#    ومجلد web كاملًا، بما فيه الأيقونات وملفات offline service worker.

# 3) نزّل الحزم وشغّل
flutter pub get
flutter run -d chrome

# 4) بناء نسخة النشر
flutter build web --release
```

ارفع محتوى `build/web` على أي استضافة HTTPS (Firebase Hosting / Netlify / GitHub Pages). ملفات Flutter والأيقونات تُخزّن محليًا بعد أول فتح ناجح، وبعدها يمكن فتح التطبيق دون إنترنت. يلزم HTTPS، وافتح التطبيق مرة وهو متصل لإكمال التخزين المؤقت.
على الآيفون: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية». على الأندرويد: Chrome ← «تثبيت التطبيق».

## تطبيق iOS وFace ID
- يتطلب بناء تطبيق iOS جهاز Mac عليه Xcode؛ شغّل `flutter pub get` ثم `flutter build ios --no-codesign`، وبعدها افتح `ios/Runner.xcworkspace` في Xcode واضبط توقيع التطبيق قبل تثبيته على الآيفون.
- في تطبيق iOS الأصلي، تُقفل أرقام الدخل في تبويب المدرسة ويُطلب Face ID لعرضها، وتُقفل مجددًا عند مغادرة التطبيق. يجب إعداد Face ID على الجهاز.
- نسخة الويب/PWA تظل دون قفل بيومتري؛ Face ID متاح في تطبيق iOS الأصلي فقط.

## طريقة الحساب
- **المدرسة**: اليومية = المرتب ÷ عدد أيام عملك في نفس الشهر. اليوم اللي بتعلّم عليه «ماروحتش» بيتخصم.
- **دخل اليوم في تبويب المدرسة**: اليومية المدرسية عند تسجيل الحضور + أسعار حصص البرايفت المنفذة والمؤكدة في سجل اليوم. إضافة حصص البرايفت هنا لا تغيّر إجماليات الملخص أو الشهر.
- **السنتر**: التحصيل الشهري يتابع الطلاب اللي اتعلّم عليهم «دفع». في الملخص، قيمة الحصة المنفذة = سعر الطالب الشهري ÷ ٨ × عدد طلاب المرحلة، وتُضاف بتاريخ تسجيل الحصة. المصاريف الشهرية بتتوزع على الأيام.
- **البرايفت**: كل طالب عنده ٨ خانات. لما تسجّل حصته في آخر اليوم تُضاف قيمة الحصة للملخص بتاريخها؛ زر «استلمت» يتابع التحصيل الفعلي منفصلًا.
- **تسجيل الحصص**: بتظهر مجموعات السنتر وطلاب البرايفت المواعيد المحددة لهم في اليوم المختار فقط، مع إبقاء الحصص المسجلة بالفعل قابلة للتعديل.
- **مواعيد الحصص**: لكل يوم تختاره ميعاد مستقل للسنتر وللبرايفت، مع استمرار قراءة المواعيد القديمة ذات الوقت الموحد.
- **الحصص السابقة**: عند إضافة أو تعديل مرحلة سنتر أو طالب برايفت، يمكن اختيار الأيام السابقة من التقويم لتظهر الحصص في سجلات الأيام وتُحسب ضمن حصص الطالب ومستحقاته.
- **الملخص**: اليوم والأسبوع والترم تعرض الدخل المكتسب من الحضور والحصص المؤكدة بتاريخ تنفيذها. الشهر يعرض المقبوض فقط: تسجيل استلام مرتب المدرسة من تبويب المدرسة، ومدفوعات السنتر والبرايفت من أماكنها. قيمة حصة السنتر = سعر الطالب الشهري ÷ ٨ × عدد طلاب المرحلة، وحصة البرايفت بسعر الحصة المسجل. عند بداية شهر جديد يظهر تنبيه بالفروق بين قيمة الشغل والمقبوض للشهر السابق، لكل مصدر على حدة. بيانات الأيام السابقة تظل محفوظة والفترات الحالية لا تشمل المستقبل.
- **الترم**: الأول من 1 سبتمبر لـ 31 يناير، والتاني من 1 فبراير لـ 30 يونيو.
- **صافي الدخل المكتسب** = دخل المدرسة + دخل حصص السنتر − مصاريف السنتر + قيمة حصص البرايفت. **صافي المقبوض الشهري** = المرتب المستلم + تحصيل السنتر + تحصيل البرايفت − مصاريف السنتر.

## المنبه (مهم)
- التطبيق الأصلي على iPhone يطلب إذن الإشعارات، ثم يجدول إشعارًا متكررًا قبل كل موعد حصة بـ١٥ دقيقة. الإشعار يوضح نوع الحصة واسم الطالب المسجل، وتظهر الحصة القادمة واسم الطالب أيضًا على الشاشة الرئيسية. يتم تحديث الإشعارات عند تعديل المواعيد.
- عند رفض الإذن، فعّل إشعارات مُنظم من إعدادات الجهاز. إشعار الحصة خارج التطبيق متاح في تطبيق iOS الأصلي؛ نسخة الويب/PWA تعرض موعد الحصة داخل التطبيق فقط ولا تضمن إشعارات عند إغلاق المتصفح.
- يظل منبه تسجيل حصص اليوم منفصلًا: بعد ميعاده (الافتراضي 9 م، ويمكن تغييره من الإعدادات) يفتح شاشة التسجيل تلقائيًا عند استخدام التطبيق إن لم يُسجّل اليوم.
